STEP 02 / 通道

选择微信接入方式

个人微信没有官方开放接口。这里提供三种真实可用的通道，请按你的情况选择。

企业微信官方接口

通过「自建应用」收发消息、同步通讯录与外部联系人。需要企业管理员在后台创建应用并开启相应权限。

回调地址填：

自建微信网关

个人微信需由你自己的网关（如 Wechaty 等）扫码登录后，以 HTTP 接口把消息转发给本站。本站不接触你的微信密码。

网关接口约定（3 个接口） 
GET  {base}/contacts
  → {"contacts":[{"id":"wxid_xxx","name":"林晚"}]}

GET  {base}/messages?since=1700000000000
  → {"messages":[{"contact_id":"wxid_xxx","content":"在吗","created_at":1700000000000}]}

POST {base}/messages/send
  {"contact_id":"wxid_xxx","content":"【AI回复】在的"}

也可以让网关主动推送：POST /api/ingest，Header 带 X-Gateway-Token。
