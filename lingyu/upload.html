上传图片

把图片直接提交到 GitHub 仓库，不需要打开 GitHub 网页。上传成功后会自动生成可用的图片地址，复制到页面里即可。

1

仓库连接

只需配置一次，会自动保存在本机浏览器

Token 需要 Contents: Read and write 权限（Fine-grained token，只授权这一个仓库即可）。Token 只保存在你的浏览器里，不会发往 GitHub 以外的地方。

2

选择图片

支持 PNG / JPG / WEBP / GIF / SVG，可多选或直接拖入

+
拖图片到这里，或点击选择 上传前可以修改文件名，建议使用英文与短横线

还没有选择图片。

提示：页面本身是静态的，所有上传都直接由浏览器调用 GitHub API 完成。图片提交后会出现在仓库的指定目录，GitHub Pages 部署完成后即可通过对应地址访问。
